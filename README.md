# 🏠 CampusNest

> Digitizing college hostel life — one room at a time.

## 🚀 Features
- ✅ Digital room cleaning tracker
- ⚡ Issue reporting (electrical, water, maintenance)
- 👥 Role-based access (Student / Warden / Admin)
- 📊 Admin dashboard with status overview

## 🛠️ Tech Stack - For Reference
- **Frontend:** HTML, CSS, JavaScript (v0.dev AI-generated UI)
- **Backend:** Node.js + Express.js
- **Database:** MongoDB Atlas
- **Auth:** Firebase Authentication
- **Tools:** Git, GitHub, Postman
